Email Checker

Checks whether an email address exists, without sending any email.

Most checks take 2–10 seconds. Outlook, Hotmail and Yahoo addresses usually come back "unknown" from home internet connections, because those providers block home IP addresses. While a bulk run is going, single checks may ask you to wait a minute.
